# New York State Spill Incidents Analysis

A Python data-analysis and geospatial-mapping project exploring reported spill incidents across New York State, with additional analysis of chemicals classified by OSHA as highly hazardous.

## Project Overview

This project explores a large dataset of spill incidents reported in New York State. The original dataset contains information about approximately 497,000 records, including spill dates, locations, contributing factors, sources, materials involved, quantities released and quantities recovered.

The project began as an exercise in exploring and cleaning a large real-world environmental dataset. My background in chemical engineering and process safety also led me to investigate the data from a hazardous-materials perspective, including identifying spills involving chemicals appearing on OSHA's list of highly hazardous chemicals.

The analysis includes data cleaning and transformation, exploratory data analysis, visualization, geocoding and interactive geographic mapping.

## What the Project Does

The Jupyter notebook:

* Imports and examines the raw New York State spill-incidents dataset
* Cleans and restructures dates and other fields for analysis
* Explores spill incidents by factors including material, source, location and time
* Uses pandas, Matplotlib and seaborn for data analysis and visualization
* Compares reported spill materials with OSHA's list of highly hazardous chemicals
* Uses geopy to geocode spill locations
* Creates latitude and longitude data for mapped incidents
* Uses Folium to generate an interactive map of hazardous-chemical spill locations
* Examines petroleum and other categories of spills over time

The notebook expects the NYS spill dataset as:

```text

```

The repository contains this dataset in compressed form as `spill-incidents.csv.zip`, so it may need to be extracted before running the notebook from the beginning.

## Geocoding

The project uses the Nominatim geocoding service through geopy to convert spill locations into geographic coordinates.

During the original analysis, repeated geocoding requests sometimes timed out. I therefore processed the locations in stages and saved the successfully geocoded results to `StateOfNY_HazchemSpills_coords.csv`. This allows the later mapping portions of the analysis to be explored without repeating the entire geocoding process.

## Data Sources

The primary spill-incidents data was published by New York State and obtained for this project through Kaggle's New York State Spill Incidents dataset.

The highly hazardous chemicals data is based on OSHA's list of Highly Hazardous Chemicals, Toxics and Reactives associated with the Process Safety Management standard, 29 CFR 1910.119 Appendix A.
